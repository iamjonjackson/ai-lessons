# ai-lessons

Interactive, web-based lessons built from existing materials. The original sources are credited in each lesson.

Open `index.html` to browse all lessons.

## Lesson ideas

Have an idea for a lesson? [Raise an issue](../../issues/new).

## Contributing

Want to contribute? Fork the repo and raise a pull request.

Guidelines:

- Each lesson is a single, fully self-contained HTML file with its own self-contained styling. Existing lessons can be used as a template if desired.
- AI-generated lessons are encouraged, as long as they are based on underlying reputable sources which are cited clearly in the lesson.
- Add your lesson to `index.html`.
